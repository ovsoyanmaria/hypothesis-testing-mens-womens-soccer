# Hypothesis Testing with Men's and Women's Soccer Matches

## Project Overview

This DataCamp project investigates whether women's international soccer matches produce more goals than men's matches using statistical hypothesis testing.

## Objectives

- Clean and prepare match data
- Compare goals scored in men's and women's international matches
- Perform hypothesis testing
- Interpret the statistical results

## Technologies

- Python
- pandas
- NumPy
- SciPy
- Jupyter Notebook

## Files

- `notebook.ipynb` – complete analysis
- `men_results.csv` – men's match data
- `women_results.csv` – women's match data

## Results

The analysis evaluates whether the average number of goals scored in women's international matches is significantly greater than in men's matches.
